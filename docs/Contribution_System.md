# PrepFlow Community Contribution System

## Vision

**Built by Students. Verified by the Community.**

PrepFlow is designed to become a community-driven learning platform where students help improve educational resources for other students. Every contribution goes through a structured review process to ensure high quality, accuracy, and trust.

The goal is to build a self-sustaining ecosystem where the community continuously improves the platform while maintaining strict quality standards.

---

# Objectives

* Allow students to contribute useful educational resources.
* Keep all resources updated with the latest syllabus.
* Detect and replace outdated or broken resources quickly.
* Reduce dependency on a single administrator.
* Build an active and trusted student community.

---

# Contribution Workflow

```text
Student
    │
    ▼
Submit Contribution
    │
    ▼
Pending Review
    │
    ▼
Reviewed by Community Reviewer
    │
    ▼
Approved / Rejected / Changes Requested
    │
    ▼
Published
```

No contribution is published directly.

Every submission must pass the review process.

# Contributor Levels

## Level 0 — Explorer

Default user.

Permissions

* Study resources
* Report issues

---

## Level 1 — Contributor

Can

* Suggest new resources
* Suggest notes
* Suggest playlists
* Report broken links
* Report outdated resources

Cannot publish anything directly.

---

## Level 2 — Verified Contributor

Requirements

* Consistent quality contributions
* High trust score
* Good approval history

Permissions

* Review beginner submissions
* Approve basic contributions

---

## Level 3 — Subject Reviewer

Specialized reviewers for individual subjects.

Examples

* Maths Reviewer
* Physics Reviewer
* Chemistry Reviewer

Permissions

* Review subject-specific submissions
* Approve high-quality resources
* Request modifications

---

## Level 4 — Community Mentor

Responsibilities

* Review reviewer decisions
* Resolve conflicts
* Maintain overall quality
* Guide new contributors

---

## Level 5 — PrepFlow Admin

Final authority.

Responsibilities

* Final approvals
* System configuration
* User management
* Role promotions
* Policy enforcement

---

# Review Process

Every submission is evaluated based on:

* Resource Quality
* Latest Syllabus
* Working Links
* Accuracy
* Relevance
* No Copyright Violations

Possible outcomes

* Approved
* Rejected
* Changes Requested

# Contributor Profile

Every contributor will have a public profile containing:

* Name
* Profile Photo
* Contributor Level
* Total Points
* Approved Contributions
* Rejected Contributions
* Approval Rate
* Trust Score
* Joined Date
* Badges

---

# Trust Score

Every contributor has a Trust Score.

It is calculated using factors such as:

* Approval Rate
* Review Accuracy
* Spam Reports
* Community Feedback
* Quality of Contributions

Higher Trust Score unlocks higher responsibilities.

---

# Points System

Example scoring model:

| Action             | Points |
| ------------------ | -----: |
| Approved Resource  |    +20 |
| Valid Issue Report |    +10 |
| Broken Link Report |     +5 |
| Helpful Review     |    +10 |
| Wrong Approval     |    -30 |
| Spam Submission    |    -20 |

Points are based on quality, not quantity.

# Publishing Policy

No user can publish content directly.

Every contribution must follow the review workflow before becoming publicly available.

This ensures that PrepFlow maintains consistent quality and trust.

# Long-Term Vision

PrepFlow should gradually evolve from a founder-managed platform into a trusted community-driven ecosystem.

Instead of relying on a single person to maintain thousands of educational resources, the community will continuously discover, improve, review, and maintain content together.

The founder and admin team remain responsible for governance and quality, while contributors help PrepFlow grow into a sustainable platform for future students.
